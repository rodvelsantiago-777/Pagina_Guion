# Fuentes de reconstrucción

Estos archivos originales se usan para reproducir las bibliotecas locales. No se copian a GitHub Pages: el navegador usa sus versiones empaquetadas de `vendor/`.

- `courier-prime/`: las cuatro TTF originales verificadas por `../build-screenplay-fonts.cjs`. Licencia SIL OFL 1.1 en `../../vendor/LICENSE-CourierPrime.txt`.
- `dictionary-es/`: fuentes AFF/DIC de dictionary-es 4.0.0, conservadas por `../build-spelling.cjs`. Licencias MPL-1.1 y del diccionario en `../../vendor/LICENSE-MPL-1.1.txt` y `../../vendor/LICENSE-dictionary-es.txt`.

Versiones, procedencia y comandos completos: `../../vendor/README.md`. Los generadores mantienen los datos y licencias necesarios para reproducir las bibliotecas.
